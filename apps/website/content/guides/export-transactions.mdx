When your accountant asks for the month's figures, you can send them a spreadsheet of your transactions, with the receipts in the same download.

## Export transactions

1. Select **Transactions** in the sidebar.
2. Narrow the list to what you need. For example, filter by **Date** for the month, or by **Category**. See [Categorise transactions](/guides/categorise-transactions) for how filters work.
3. Tick the transactions to export. Tick the box in the header to select every transaction on the page.
4. Select **Export** in the bar at the bottom of the screen.
5. Choose a format: **CSV** or **Excel (XLSX)**.
6. To send it to someone, turn on **Send by email** and enter their address. It starts with yours.
7. Select **Export**. The button shows how many transactions you've selected.

Travada Books builds the file in the background. When it's ready, the file downloads in your browser. If you need it again, select **Download again** in the message that appears.

If you turned on **Send by email**, the address you entered also gets an email with a download link. The link expires after 7 days.

> **Good to know:** The list shows 50 transactions a page, and you export from the page you're on. For a longer period, filter it down or export it in parts.

## What's in the file

Each transaction is one row, with these columns:

- **Date**, **Name** and **Counterparty** (who paid you or who you paid)
- **Type** (Income or Expense), **Amount**, **Currency** and **Formatted Amount**
- **Category**, **Status** and **Payment Mode**
- **Reference Number**
- **Tax Amount**, **Tax Rate (%)** and **Tax Type**
- **Recurring**, **Note** and **Attachments**

The **Attachments** column shows how many files each transaction has.

## Receipts and attachments

If any of the transactions you export have files attached, you get a ZIP file instead of a single spreadsheet. Inside is the spreadsheet and an **attachments** folder, with one folder per transaction named by its date and description. Your accountant can find the receipt for any line without asking you.

## Before you send it to your accountant

- Check the **Category** of every transaction. Anything still blank will be blank in the file too.
- Attach any missing receipts first, so they're in the ZIP. See [Add transactions and attach receipts](/guides/add-transactions-and-attach-receipts).
- Add a **Note** to anything unusual. Notes are included in the file.
- Use **Send by email** with your accountant's address, so they get the file directly.

To download everything in your account at once, see [Export or delete your data](/guides/export-or-delete-your-data).
